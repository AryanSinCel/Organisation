Organisation App
==========

Overview
--------

The Organisation App is a SwiftUI-based Company Employee management application that allows users to browse add, delete, update Employee and Company. The app integrates Core Data for for CRUD functionality for Company and Employee with also following MVVM architecture pattern in mind.

Features
--------

*   **SwiftUI Interface**: A modern and smooth UI for a seamless user experience.
    
*   **Core Data Integration**: CRUD operation on Company and Employees and relationship.
    
*   **MVVM**: Followed MVVM architecture design pattern.

*   **Search**: Filter the data on the basis of employee name or company name.

    

Technologies Used
-----------------

*   SwiftUI - For building the user interface.
    
*   Core Data - For persistent data storage and authentication management.
